# 复现过程中值得先查的问题

这些是整理UWB测距与惯性融合资料时积累的通用检查方法。它们可以帮助判断“代码能运行”和“实验可以比较”之间还差什么。

| 现象 | 先查什么 | 一个小验证 |
|---|---|---|
| 换个数据集就完全不对 | 距离单位、时间单位、CIR截取与幅值归一化 | 从一行原始记录算出输入并画波形，不直接套训练脚本 |
| CIR模型分类很好，测距仍很差 | 任务是分类还是连续偏差回归 | 分别画分类混淆与测距残差；不能用分类准确率代替定位误差 |
| 距离变准，定位没有变化 | 修正量符号、传感器事件是否实际更新、方差映射是否压平差异 | 对同一个测量打印原距离、修正距离及实际更新权重，检查变化有没有进入状态 |
| 加入IMU后反而漂移 | 重力是否去除两次、body/world坐标、姿态旋转方向 | 构造静止与已知方向加速度，检查传播的速度和位置变化 |
| ESKF姿态或偏置变化过大 | 左右扰动、误差状态定义、可观测性、异常量测反馈 | 对照Solà约定，检查Jacobian，并先固定一个偏置分量作机制对照 |
| 代码处理UWB，却接不上数据 | 输入究竟是位置、单条距离，还是锚点对距离差 | 对照TWR/ToA/TDoA观测方程与锚点ID，不只改列名 |
| 鲁棒参数换个库就失效 | 残差是否白化，阈值是米还是标准差倍数 | 用一个固定残差计算损失和权重，核对SciPy/GTSAM各自定义 |
| 同名Student-t方法结果不一致 | 自由度、尺度与协方差、状态后验近似 | 先核对原论文公式，确认不是只用了同一个分布名称 |
| 随机分帧很好，换环境很差 | 相邻样本相关、房间/锚点/轨迹是否跨集合 | 根据实际泛化目标做环境、轨迹或时间隔离，保留同协议强基线 |
| 同名数据文件结果对不上 | 数据是否修订过，波形与meta索引是否一致 | 保留下载版本和样本ID，特别查看上游V2修订说明 |

复现入口优先选有论文、数据说明和具体运行命令的作者项目。第一次先保存原配置结果，再改变一个因素。缺少某个输入或许可时明确记录，不把自己改过的版本直接称为原作者方法。
