# UWB + 简化 IMU 的二维 EKF 教学示例

本目录是一个独立、公开安全的**合成数据教学包**。所有轨迹、加速度、偏航角、UWB 距离和输出文件都由代码生成，运行结果统一标注 `SYNTHETIC_TEACHING_ONLY`。它用于讲解标准EKF基础，不是定位产品或完整科研系统。

## 公开文件

- `README.md`：运行方法、阅读顺序、坐标系、时钟和限制。
- `math_notes.md`：平面 Kalman/EKF、距离观测雅可比和过程噪声的入门数学。
- `demo_uwb_imu_ekf.py`：四状态平面 EKF 与 IMU 航位推算基线。
- `requirements.txt`：仅 `numpy` 与 `matplotlib`。
- `OPEN_SOURCE_SCOPE.md`：本教学包公开范围与明确不公开内容。
- `.gitignore`：忽略虚拟环境、缓存和生成输出。
- `reading_template.md`：从问题、假设、方法、证据到个人判断的阅读记录。
- `experiment_log_template.md`：帮助保存设置、指标口径、负结果和下一步的小实验记录。

压缩包的`examples/`保留一张真实运行生成的合成演示图和摘要，方便先看效果；它们与任何真实数据或研究性能无关。


## 安装与运行

只依赖 NumPy 和 Matplotlib。建议在独立虚拟环境中安装 `requirements.txt` 中的两个包。

先运行自检。自检不会写输出目录：

```text
python demo_uwb_imu_ekf.py --self-check
```

再生成一次完整合成演示。`--out` 必须是**尚不存在**的目录；程序会拒绝覆盖已有目录：

```text
python demo_uwb_imu_ekf.py --out demo_output
```

指定输出目录后会生成：

- `synthetic_demo.png`：真实合成轨迹、EKF、IMU 航位推算，以及位置误差曲线。
- `synthetic_states.csv`：逐时刻合成真值、EKF 状态、航位推算位置和离线误差。
- `summary.json`：配置、噪声、假设、离线指标和 `SYNTHETIC_TEACHING_ONLY` 标签。

如果 `demo_output` 已存在，请换一个新目录名，例如 `demo_output_02`。程序不会删除或复用旧结果。

## 先建立一个可复现基线

建议顺序：

1. 先运行自检，确认距离雅可比、常加速度传播和 Joseph 协方差检查通过。
2. 用默认设置生成基线，观察轨迹和误差曲线。
3. 只修改一个噪声因子，例如距离噪声 `RANGE_SIGMA`，再用新的输出目录重跑。
4. 比较差异时同时查看轨迹、误差曲线和随机种子，不只报一个末尾数字。

固定随机种子让示例可复现，但“固定几次种子再作 t 检验”不是本示例的要求。这里的误差在时间上相关，且轨迹是固定的合成样本；重复种子可用于检查定性稳定性，不应把相关样本当成独立重复实验来做显著性声明。

## 观测与传播怎么读

状态是平面位置和速度：

```text
x = [px, py, vx, vy]^T
```

每个 `0.1 s` 步，滤波器用测量到的世界系水平加速度做一次预测：

```text
x_k+1 = F x_k + B u_k
P_k+1 = F P_k F^T + Q
```

其中 `u_k` 来自外部提供的偏航角测量：先把机体前向/左向水平加速度按测量偏航角旋转到世界系。预测步不使用合成真值。

UWB 只提供“锚点到目标的标量距离”，每 `0.5 s` 到达一次：

```text
z = sqrt((px - ax)^2 + (py - ay)^2) + noise
H = [ (px - ax) / r, (py - ay) / r, 0, 0 ]
```

在观测时刻，用标准高斯 EKF 更新，并用 Joseph 形式计算后验协方差。没有距离观测的中间步只做预测。代码中的 EKF 预测和更新函数只接收状态、协方差、输入或测量，不读取合成真值。

IMU 航位推算基线使用**完全相同的初始状态和同一组测量加速度输入**，但没有 UWB 更新。它展示仅积分带噪声加速度会如何漂移，而不代表一套完整惯性导航系统。

## 时钟、坐标系和初始条件

- 采样周期 `dt = 0.1 s`，总时长 `60 s`。
- 距离每 `0.5 s` 更新一次，代码假定 UWB 与 IMU 使用同一时钟且时间戳对齐。
- 坐标系为二维世界平面，偏航角从世界 `+x` 轴逆时针测量；机体 `+x` 为前向、`+y` 为左向。
- 机体水平加速度按**外部测量偏航角**旋转到世界系。
- 已假定二维重力分量被移除。本示例不是完整 INS，也不估计姿态。
- 初始状态由固定名义位姿加一个小扰动得到，且**不依赖带噪距离**。这是方便教学的“已知起点”假设，不是生产初始化方案。
- 生产系统需要处理初始化、时间偏移、丢包、外参、姿态误差、异常值和更真实的误差相关性；这些都不在本示例范围内。

## 可以学到什么，不能外推什么

可以学习：四状态平面运动模型、带输入的过程噪声、标量距离观测、EKF 线性化、Joseph 协方差的写法，以及“有 UWB”与“仅 IMU 积分”的基线差异。

不能据此声称：鲁棒 NLOS 抑制、抗多径、学习型测距、Student-t 鲁棒滤波、自适应风险控制、IMM、经过标定的传感器模型、真实场景精度、SOTA 或新颖性。演示只使用高斯噪声和简化的距离观测，也没有真实数据、CIR 输入或学习网络。

本示例不可用于安全关键导航、定位产品验收或对真实系统性能的承诺。
